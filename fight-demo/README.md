## Что нового в v3 (2026-11-09) — все рекомендации ревьюверов

- **Зоны кота**: морда — КРИТ −2 🐟, хвост — ФОЛ (жертва бесится: +15% скорость), тело −1.
- **Финты**: второй мазок = фантом-обманка; враг видит обе лапы одинаково первые 300 мс (серые), дальше настоящий удар цветной. Бот финтит с P=0.35.
- **Анти-спам клинчей**: три синхро-лязга подряд → «вялые лапы» (−25% скорость до конца раунда).
- **Девятая жизнь**: при 1 рыбке окно продавливания шире (115 → 144 мс).
- **Sudden death**: при 1:1 следующий раунд без блоков — только чистые хиты.
- **Пост-мортем** (🔍): победитель жёлтым, проигравший пунктиром, времена прилётов, подписи зон.
- **Призраки**: бледные дуги прошлых раундов (до 3 пар) прямо на арене.
- **HUD-гонка**: мини-таймлайны прилёта A/B с мс в правом верхнем углу.
- Самотест: **28 гейтов** (`ST20`–`ST28` новые: зоны, крит, хвост, финт, девятка, анти-спам, sudden, звук, призраки).

## Что нового в v2 (2026-11-09)

- Пари-клинч «кто кого переуличил» (timing): окно 115 мс, синхро 25 мс, продавливание опоздавшего.
- Метки времени на мазке, juice-эффекты, SFX-синтез без ассетов.
- Самотест: 19 гейтов (`?selftest=1`).
- **Пари-клинч** (главное, из IDEAS.md): в timing-режиме клинч больше не ничья.
  Окно ±115 мс от момента встречи лап в точке пересечения:
  - Δ ≤ 25 мс — **синхро-лязг**, оба удара сбиты (ничья раунда);
  - 25 < Δ ≤ 115 мс — **ПАРИРОВАНИЕ**: ранний бьёт продавливает и доезжает (может снять рыбку),
    плашка «X ПАРИРОВАЛ И ПОДЪЕБАЛ! (опередил на N мс)»;
  - Δ > 115 мс — пролёт мимо, удары не встретились.
  Клинч-спам как бесплатная стратегия исчез: опаздывать наказуемо.
- **Метки времени на мазке**: точки каждые 100 мс (крупные каждые 500 мс) в live-рисовании,
  playback и итоговой схеме (золотые тики). Длина замаха = время прилёта — теперь видно глазами.
- **Живой статус при рисовании**: «замах N px · полёт ~N мс» (обновление каждые 80 мс).
- **Juice**: freeze-frame 90 мс в точке клинча/удара, screen-shake 340 мс,
  squash&stretch котов при хите (Ø-колокол 450 мс), burst-частицы 26/34, вспышки.
- **Звук без файлов** (WebAudio-синтез): лязг синхро, глухой пари-тычок, pop рыбки, fanfare победы.
  Кнопка 🔊 в HUD; звук стартует после первого клика (autoplay-политика).
- Пари-хит списывает рыбку **жертве** (кто опоздал), не автору пари.

## Механика
- Матч: у каждого кота **3 рыбки** (HP). Раунды, до нуля рыбок у одного.
- Рисование: мышью за один мазок траекторию удара (≥60 px); hotseat — с экраном-ширмой
  «передай мышку», против бота — рисует бот (Catmull-Rom с шумом).
- Разрешение раунда (`resolveRound`):
  - **«по ТЗ» (режим по умолчанию)**: любое геометрическое пересечение полилиний = КЛИНЧ — оба удара сбиты.
  - **«тайминг» (переключатель в лобби)**: блок только если движущиеся лапы (Ø26px, равномерно
    по arc-length за общий dur) встретились одновременно; длина замаха задаёт «когда прилетишь».
  - Нет блока → конец траектории в эллипсе кота (108×130 у корпуса) = попадание, −1 рыбка.
- Проигрывание: обе лапы бегут по кривым ~520 px/s, при клинче упираются в чужую линию
  и стопорятся до столкновения (искры, «КЛИНЧ!»), при попадании — «БАМ!», усыпление рыбки, jelly-отскок кота.
- Исходы: клинч / обмен / одностороннее попадание / оба в молоко / обоюдный нокаут.

## Вердикт спайка: VALIDATED (с оговоркой баланса)
- Идея «рисуем удары → пересечение = блок» играбельна и выглядит живо.
- **Сюрприз**: в режиме «по ТЗ» оба удара через центр почти всегда пересекаются →
  ~70% раундов стоят клинчем. Режим «тайминг» решает: появляется игра в длину замаха
  (короткий мах проскакивает точку раньше — ловишь вражескую линию или разминаешься).
- Playback не зависит от rAF (события на таймаутах + опорные кадры): matte-env safe.
