# Котобитвы — прототип боёвки coop-field

Дата: 2026-11-09. Спайк по ТЗ заказчицы: «два кота смотрят друг на друга, челы мышкой
рисуют траектории ударов, когда оба нарисовали — бой воспроизводится; пересеклись
траектории — блок, не пересеклись — подъебал».

## Механика
- Матч: у каждого кота **3 рыбки** (HP). Раунды, до нуля рыбок у одного.
- Рисование: мышью за один мазок траекторию удара (≥60 px); hotseat — с экраном-ширмой
  «передай мышку», против бота — рисует бот (Catmull-Rom с шумом).
- Разрешение раунда (`resolveRound`):
  - **«по ТЗ» (режим по умолчанию)**: любое геометрическое пересечение полилиний = КЛИНЧ — оба удара сбиты.
  - **«тайминг» (переключатель в лобби)**: блок только если движущиеся лапы (Ø26px, равномерно
    по arc-length за общий dur) встретились одновременно; длина замаха задаёт «когда прилетишь».
  - Нет блока → конец траектории в эллипсе кота (108×130 у корпуса) = попадание, −1 рыбка.
- Проигрывание: обе лапы бегут по кривым ~520 px/s, при клинче упираются в чужую линию
  и стопорятся до столкновения (искры, «КЛИНЧ!»), при попадании — «БАМ!», усыпление рыбки, jelly-отскок кота.
- Исходы: клинч / обмен / одностороннее попадание / оба в молоко / обоюдный нокаут.

## Как проверено (2026-11-09)
- **Самотест 15/15**: сегментные пересечения (крест, параллель, коллинеар+перекрытие/без, касание),
  arc-length, клинч «any», двойное попадание, оба мимо, одностороннее, снятие 3 рыбок → победа,
  обоюдный нокаут → ничья, тайминг-клинч/разминка, чтение radio.
- **Живые матчи через программную мышь (PointerEvent)**: бот-матч в timing — 4 раунда
  (попадание → обмен → клинч → победа 1:0); «any»-режим — 7 раундов, лобовых клинчей ~5/7 (см. вердикт).
- **Пиксельные пробы канваса**: точки на траектории = цвет игрока (251,144,115), вне линии — фон поля.
- **Vision-QC (haiku, router.py)**: клинч-схема 5/5 (траектории/маркер/плашка/коты/рыбки),
  финал матча — все пункты, лобби — все элементы.

## Вердикт спайка: VALIDATED (с оговоркой баланса)
- Идея «рисуем удары → пересечение = блок» играбельна и выглядит живо.
- **Сюрприз**: в режиме «по ТЗ» оба удара через центр почти всегда пересекаются →
  ~70% раундов стоят клинчем. Режим «тайминг» решает: появляется игра в длину замаха
  (короткий мах проскакивает точку раньше — ловишь вражескую линию или разминаешься).
- Playback не зависит от rAF (события на таймаутах + опорные кадры): matte-env safe.

## Рекомендации для прод-версии (когда понравится)

3. Звук (сейчас без), частицы шерсти при хите, счётчик раундов в HUD.
