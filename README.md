# KNS — конструктор окрасов для coop-field

Прототип редактора окрасов (KNS, «конструктор няшных скинов») для игры
[coop-field / abnocw](https://abnocw.miew.ru) (организация
[gertha-puzik](https://github.com/gertha-puzik)).

Что здесь лежит:

- `index.html` — редактор окрасов: 24 слота, послойная тонировка, 8 палитр,
  walk-цикл, случайный окрас, экспорт/импорт кода вида `id/цвет|прозр`.
- `catwar-manifest.js` — манифест слотов и шаблонов файлов (вся логика
  сборки окраса: группы, полосы, composite-тайминги [1000, 200, 200, 300] мс).
- `act0/`, `act1/` — спрайты-послойные PNG (сид/ходьба) для всех элементов
  и id окрасов.REFERENCE Арт — референс **CatWar** (https://catwar.su),
  спарсен для прототипа; в игре coop-field НЕ используется напрямую.

## Сайт

Публичная копия прототипа: **https://kns.miew.ru** (VPS 89.232.184.77,
nginx, статика из `/opt/kns/www`).

## Деплой

CI/CD: GitHub Actions, `.github/workflows/deploy.yml` — при пуше в `main`
rsync-ит всё содержимое репозитория в `/opt/kns/www/` на VPS
(`--delete`, исключая `.git`/`.github`). Секрет репозитория `VPS_SSH_KEY`
— приватный SSH-ключ юзера `deploy` (отдельный от coop-field).
Отпечаток хоста VPS закреплён прямо в workflow.

Ручная проверка без CI: открыть `index.html` локально в браузере —
прототип полностью офлайн, сервер не нужен.

## Скиллы/регламенты (для ИИ-агентов)

`KNS-CONTEXT.md` (корень) — досье проекта одним файлом; `skills/kns-imagegen/`
— регламент генерации спрайтов в стиле M2 (SKILL.md + скрипт конвейера
`kns_sprite_pipeline.py` + шаблон ТЗ-брифа + контр-тесты vision-QC).
Канон обеих — здесь, в репо; `skills/` и досье исключены из деплоя
(на kns.miew.ru не попадают). Зеркала скиллов живут в Hermes-профиле
агента (`~/.hermes/skills/software-development/kns-imagegen`) — синхронизировать
с копией в этом репо при изменениях.

## Согласование промежуточных результатов

Чек-лист согласования превью до мержа — `KNS-CONTEXT.md` §8.8:
единое место превью — вложения канбан-карточки этапа (при сдаче этапа
нотификатор доставляет их нативными вложениями в ТГ-чат подписки
заказчицы); пакет превью = живые GIF всех затронутых анимаций на фоне
поля + контакт-лист + цифры QC + ссылки; согласовано = явное «ок»
заказчицы на конкретный пакет (до «ок» карточка-гейт стоит blocked,
мержа нет); каждая новая перегенерация = новый пакет и новый круг.


## Правовая оговорка

Арт в `act0/`, `act1/` и данныe манифеста — собственность CatWar
(спарсен с их публичного KNS-редактора как референс механики).
Публичный репозиторий с этим артом не открывать; `kns_def.json`
и изображения CatWar в репозиторий coop-field НЕ коммитить (решение
владельца проекта).
