# Генерация спрайтов KNS (стиль M2)

Регламент «получить желаемый кадр с минимумом перегенераций» для конструктора окрасов kns.miew.ru. Выжимка гонок 2026-11-04..05 (12 серий + ракурсы + bodyforms) — пороги проверены на принятых заказчицей кадрах. Домен (слоты, слои, /archive, прод) — скилл coop-field-kns; инструмент-роутер — selectel-ai-router; этот скилл — сам конвейер генерации. Канон живёт в репо kns: `skills/kns-imagegen/` (в деплой исключён).

## When to Use
Любая задача «сгенерировать/перегенерировать спрайт для KNS»: новые ракурсы и направления walk (N/S/W/E), телосложения, варианты хвоста, элементы-драфты в стиле M2, альтернативы по отклонениям заказчицы, QC готовых кадров/листов. НЕ для программной тонировки полного набора окрасов (это маски M2 — см. coop-field-kns) и не для генераций вне kns.miew.ru.

## Границы (каждый раз)
- Полный набор окрасов — ПРОГРАММНАЯ тонировка масок M2, не ИИ-масс-генерация; ИИ — только новые ракурсы/телосложения/элементы-драфты и альтернативы по отклонениям заказчицы.
- Габарит: хвост/новые детали строго в ПРЕДЕЛАХ ширины эталонного силуэта. «Хвост торчит вбок» = конвейер ужмёт кота при фите (w2 sit-taildown: кот 97 px вместо 106) либо хвост обрежется кромкой. В промпты новых хвостов/элементов — HARD CONSTRAINT: «silhouette width must stay within the reference». Пиксель-контроль после фита: тёмный контур на кромках кадра — в коридоре эталона (родной M2s_f: L19/R10), плюс сверка высоты кота с эталоном.
- Арт-контракт: холст 100×150, опора по нижнему краю; тень и белый силуэт-подсветку НЕ запекать (движок рисует сам); глаза — только листом/спрайтом, не тонировать.
- Отклонённые серию НЕ перегенерировать — она помечена [ОТКЛОНЕНО] в /archive с причиной; идёшь в ту же тему = сначала читаешь карточки.
- Папка волны: `kns-generations-<дата>/<тема>/` (raw/, frames/, prompts/); каждая волна — своя подпапка w2/, сырьё не перезаписывать.

## Пайплайн (8 шагов)
1. **Инвентаризация ДО генерации.** Зеркало дешевле генерации: противоположное направление = FLIP_LEFT_RIGHT готовых кадров; двойное зеркало запрещено — сверять `W.tobytes() == flip(E).tobytes()`. Смотрим /archive: требуемый ракурс уже есть/отклонён?
2. **Палитра — из кадров, не из досье:** `pipeline.py palette mf/M2w_k0.png` → фактическая #F0B863 (тело) / #F7E2C3 (крем) / тёмно-коричневый контур. В досье договорённая #E7BD8C — для целей тонировки; подставлять её в промпты/скоры = стилевой дрейф и заниженные скоры (урок bodyforms: PAL из досье не покрывает факт ±45).
3. **ТЗ-промпты — не руками:** бриф у claude-sonnet по `references/m2-brief-template.md` (внутри — 10 известных провалов генератора; провал-лист в брифе — главный фактор качества). Промпт самодостаточен, на английском, кот = «the reference cat».
4. **Генерация:** `router.py image google/gemini-3.1-flash-image "$(cat PROMPT_X.txt)" --ref <эталон> --out raw/<серия>_<пул>.png`. Для walk референс = РОДНАЯ полоса + «copy EXACTLY the art style of the attached reference strip», не sit. Пул ≥2 (a,b), 3 параллельных воркера, ретрай 1. Файл .png может содержать JPEG — норм, PIL читает по контенту.
5. **Нарезка+метрики:** `pipeline.py process --dir <папка> --kind walk|sit [--filter <серия>] --ref-frames '<glob эталонных кадров>'` → frames/*.png + process_report.json (merge по сериям). Пол (чёрная ground line) стирается на уровне ЛИСТА до сегментации, остатки — по нижним строкам кадра; широкие блобы-полосы режутся по пустым колонкам, сплошняк — фокус-долинами (зоны k·(1/4)±0.18, НЕ глобальный argmin). ФИЛЬТРЫ — только ПОСЛЕ фита 100×150: сырой сегмент всегда «слипшийся», фильтровать его = угробить весь пул (урок bodyforms).
6. **Пороги приёмки** (арбитр — пиксели, не глаз):
   - живость соседей (доля |ΔRGB|>30 в объединённой маске α>64): ≥16%, дубль <8%; курсор-ориентиры: родная M2 51–61%, принятые N 63–64%, S 80–83%;
   - замыкание цикла 4→1: ≥12%;
   - стиль-скор (доля пикселей в палитре-эталоне ±55): ≥0.5;
   - зелёный мусор (g>r,b+25): <5%;
   - CC-острова кадра (4-связность α>40, ≥50 px): =1 — 2+ «плавающая лапа», но vision гипер-критичен, перепроверять пикселями;
   - h-разброс фаз (max−min)/max bbox: ≤25% — пивот игры нижний центр.
7. **Vision — второе мнение:** `router.py vision anthropic/claude-haiku-5.5 <склейка-лист> "вопросы"` ВСЕГДА склейкой (ряды=варианты, кадры по порядку, тёмная подложка) одним запросом. Контр-тесты к вердиктам (дубли/пивот/«дышит»/мусор) — references/qc-counterchecks.md.
8. **Подача:** живое превью (::preview, canvas 280 мс; фон — тайл поля или #616517; кадры PNG base64 в <script>-константе — НЕ JPEG, НЕ data-атрибуты) + 2–4 варианта. Статус — КАНДИДАТ до вердикта заказчицы: стилевой арбитраж — только человек (урок серии D). В карточку /archive: промпт verbatim, диффы, плюс/минус, вердикт.

## Быстрый прогон
```bash
D=kns-generations-$(date +%F)/<тема>; mkdir -p $D/{raw,frames,prompts}
python3 pipeline.py palette <эталон>.png        # палитра для промптов и скора
python3 router.py chat anthropic/claude-sonnet-5.5 "$(cat prompts/brief.txt)" --max-tokens 16000   # → PROMPT_*.txt
# пулы a/b: xargs -P 3 router.py image … --ref полоса --out raw/<серия>_<пул>.png
python3 pipeline.py process --dir $D --kind walk --ref-frames '<glob эталонов>'
python3 pipeline.py preview --frames $D/frames
```

## Files
- `scripts/kns_sprite_pipeline.py` — process / preview / palette (только PIL, drop-in).
- `references/m2-brief-template.md` — проверенный шаблон ТЗ-брифа claude-sonnet с провал-листом.
- `references/qc-counterchecks.md` — контр-тесты vision-вердиктов.
- Исторические скрипты волн (dirs-knife.py, dirs-slice2.py) — в `~/.hermes/cache/scratch/`; pipeline.py их покрывает и заменяет.
