# Контр-тесты vision-вердиктов (модель даёт правдоподобные, но часто ложные диагнозы)

Всегда гасить цифровыми проверками — арбитр пиксели, vision второе мнение. Запрос — одной склейкой:
ряды = варианты, кадры слева-направо по порядку фаз, тёмная подложка, подписи рядов, делители-сетка.

| Вердикт vision | Контр-тест | Вердикт если числа молчат |
|---|---|---|
| «кадры — дубли» | диффы ВСЕХ 6 пар (вкл. 1↔3, 2↔4): живой 4-фазный цикл меняет ~50% силуэта в любой паре; мёртвый <11% | ложная тревога |
| «пивот прыгает между кадрами» | нижняя кромка bbox по альфе (α>8) обязана совпадать во всех кадрах — пивот игры жёстко нижний центр | ложная тревога |
| «корпус дышит / масштаб пляшет» | ширина bbox стабильна = норм (дыхание — признак стиля); гуляет высота bbox = реальный дефект (уши/хвост дёргаются) | дефект реальный только по высоте |
| «мусор в кадре» | изолированные пиксели: 4-связность по α>40, компонент ≥50 px = объект; одиночные точки-соседи = шум | ложная тревога |
| «плавающая лапа/деталь» | CC-острова кадра: 1 связный силуэт = артефакта нет (vision гипер-критичен к тонким конечностям) | ложная тревога |
| «кадры слиплись / рамки» | сегментация: col-profile «котопикселей», зазор пустых колонок <5 — резать фокус-долинами; аспект «двухпозитного» пятна ≥1.6 | резать по-другому, не выкидывать |

Дополнительные фильтры позади vision:
- PIL-подписи на склейках — только ЛАТИНИЦА: дефолтный шрифт ImageDraw не рендерит кириллицу (vision видел квадраты и ориентировался вслепую).
- зелёный мусор (g>r+25 и g>b+25) <5% кадра — быстро ловит вползший фон поля;
- JPEG-под-именем-.png — PIL читает по контенту, расширению не верить (router.py сохраняет mime как есть);
- чёрная полоса-пол: строки листа, где ≥50% непрозрачных тёмные (r<120,g<95,b<95), стирать ДО сегментации — иначе слипшиеся коты не режутся;
- "первый срез canvas пуст" = картинки в полёте, не 404: перемерять ≥1-1.5 с.

Пороги живости для сравнения:
- дубль <8%; неживая анимация <11%-16% (перегенерить);
- живой цикл ≥16%; ориентиры принятых серий: родная M2 walk 51–61%, N 63–64%, S 80–83%.
